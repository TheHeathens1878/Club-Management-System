# P4.5 — media on Supabase Storage, consent-filtered (SG-5)

`supabase/migrations/20260823200000_media.sql` · Linear TH1-32 · Q4

- Private `media` bucket (25 MB, images + mp4); uploads by admins/team staff;
  **no direct reads** — the app mints signed URLs (TTL
  `media.signed_url_ttl_seconds`, 900) only for items returned by the
  functions below.
- `media_albums` (visibility team/club/public/social/press → required
  consent purpose via `album_consent_type()`), `media_items`
  (`subjects_confirmed`, `legal_hold`, `redacted_at`, `needs_quarantine`),
  `media_subjects`.
- **`authenticated` has no SELECT on `media_items` / `media_subjects`.**
  Reads are `media_gallery(album)` and `media_export(album)` — SECURITY
  DEFINER, filtered by `media_item_showable(item, purpose)`: subjects
  confirmed (**untagged fails closed**), not redacted/quarantined, and every
  minor subject holds an active consent for the purpose. A confirmed photo of
  nobody shows.
- `media_export` writes `media.bulk_export {item_count, excluded_unconsented}`
  before returning (SG-7); club_admin / team staff only.
- Withdrawal is immediate at query level, and flags every item the child
  appears in for quarantine; the `media-quarantine` Edge Function moves the
  object and calls `media_quarantined()` so old signatures break.
- SG-8: `legal_hold` lead-only; redaction refused under hold; no hard deletes.
